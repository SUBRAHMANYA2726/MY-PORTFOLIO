# Subrahmanya Manjunatha Bhat — Portfolio

Premium editorial personal portfolio — AI / ML · Software · Data.

**Open at: https://my-portfolio-jn1z.vercel.app/**

## Stack

- Next.js 15 · React 19 · TypeScript
- Tailwind CSS 4 · Framer Motion
- Contact API: `/api/contact` (MongoDB + Nodemailer, env-configured)

## Develop

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production

```bash
npm run lint
npm run build
npm start
```
